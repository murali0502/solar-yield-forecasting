## ⚡ Overview

Solar generation is influenced by continuously changing environmental
and temporal conditions.

Irradiance, cloud cover, temperature, humidity, wind conditions,
and time-dependent patterns can all affect solar output.

This project addresses the forecasting problem through a **hybrid
machine learning architecture** that combines two complementary
models:

- 🌳 **XGBoost** — learns structured feature relationships
- 🌊 **TCN** — learns temporal patterns from historical sequences
- 🔗 **Hybrid Ensemble** — combines both model predictions

The forecasting pipeline is exposed through a **FastAPI REST API**
and connected to an interactive **React + TypeScript dashboard**.

🎯 Project Objective

The goal is to build an end-to-end solar forecasting system that can:

Process environmental and temporal data
Learn structured relationships using XGBoost
Learn temporal dependencies using TCN
Combine predictions through a hybrid ensemble
Serve trained models through an API
Present forecasting results through an interactive dashboard
Provide evaluation and visualization artifacts for model analysis

🧠 Why Hybrid Forecasting?

Solar generation contains both structured relationships and
temporal behaviour.

A tree-based model and a temporal deep-learning model can therefore
approach the problem from different perspectives.

🌳 XGBoost

XGBoost processes structured environmental and temporal features.
Temperature
Humidity
Cloud Cover
Wind Speed
Irradiance
Hour
Day of Year
Cyclical Time Features

Its role is to learn relationships between the available input
features and solar output.

🌊 Temporal Convolutional Network

The TCN focuses on historical temporal behaviour.

The current implementation uses a:

24-hour lookback window
Historical Sequence

t-24 ── t-23 ── t-22 ── ... ── t-2 ── t-1 ── t
